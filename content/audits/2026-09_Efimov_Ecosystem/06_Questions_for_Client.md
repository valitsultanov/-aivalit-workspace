# Вопросы клиенту и доступы

**Проект:** ПВВК · Асатома · ЕВА
**Дата:** 28.09.2026

Ответы нужны, чтобы перевести экспертные оценки аудита в цифры и выбрать стратегию объединения.

## 1. Общие вопросы (для выбора стратегии)

- [ ] Какова юридическая структура: одно юрлицо / разные ИП и ООО? Кто собственники каждого проекта?
- [ ] Какая главная цель на 12 месяцев: деньги сейчас, масштаб сети, продажа бизнеса/инвестор, наследие Ефимова?
- [ ] Насколько В.А. Ефимов готов быть лицом ПВВК и Асатомы и сколько времени может выделять?
- [ ] Реальные цифры: выручка, количество клиентов, средний чек, базы контактов по каждому проекту.
- [ ] Какие CRM, платформы и подрядчики используются сейчас?
- [ ] Есть ли права на товарные знаки «ПВВК», «Асатома», «ЕВА», «Синусоида»?
- [ ] Какие ограничения по тону: готовы ли разделить «мировоззренческий» и «wellness»-контент?

## 2. Доступы

- [ ] Яндекс Метрика по трём сайтам (гостевой доступ)
- [ ] Яндекс Вебмастер по трём сайтам
- [ ] Статистика соцсетей (скриншоты или выгрузка за 90 дней) — по каждому каналу: подписчики, охват, ER, переходы, заявки, продажи
- [ ] CRM / платформа обучения / сервис онлайн-записи (просмотр)

## 3. ПВВК — что проверить и уточнить

- [ ] PageSpeed Insights (моб./десктоп), Core Web Vitals
- [ ] Яндекс.Вебмастер: индексация, дубли, ошибки, ИКС
- [ ] robots.txt, sitemap.xml, canonical на лендингах
- [ ] Метрика: источники, конверсия в заявку, вебвизор первого экрана
- [ ] Путь заявки: кто и через сколько отвечает (тайный покупатель)
- [ ] Статистика всех 7 каналов за 90 дней
- [ ] Какая цена и какой объём за цикл (3,5 или 5,5 л) правильные сейчас?
- [ ] Список официальных дилеров и есть ли рекомендованная розничная цена
- [ ] Документы: сертификаты/декларации, протоколы лабораторных испытаний

## 4. Асатома — что проверить и уточнить

- [ ] Выручка и загрузка по каждой точке, средний чек, % повторных визитов
- [ ] Источник первого визита (как узнали)
- [ ] Статистика соцсетей по городам
- [ ] Скорость сайта, индексация, дубли
- [ ] Тайный покупатель: запись через каждый канал в каждом городе
- [ ] Есть ли пакеты/курсы сеансов после первого визита и по какой цене?
- [ ] Номера патентов и документы на оборудование

## 5. ЕВА — что проверить и уточнить

- [ ] Платформа обучения, % доходимости, возвраты
- [ ] Источники продаж флагмана за 12 мес.
- [ ] Метрика/UTM на всех 4 доменах
- [ ] Статистика YouTube/RUTUBE/TG: какие темы дают подписку и продажи
- [ ] Индексация дублей в Яндекс.Вебмастере
- [ ] Полная линейка тарифов с ценами на сегодня
- [ ] Какие домены официальные (efimovschool.ru, .com, reset90.ru, veb.) и какие можно закрыть
