## Главный вывод в одном абзаце

Три проекта уже связаны: у них общие люди (В.А. Ефимов — лицо и эксперт, В.П. Кордюков — руководитель ПВВК и оператор персональных данных efimovschool.ru), общая тема (вода → пар → сознание/образ жизни) и одна аудитория 45+ с интересом к здоровью, долголетию и «своей картине мира». **Но для клиента это три разных магазина с тремя входами, тремя базами и тремя языками.** Человек, купивший курс Ефимова, не получает предложения попробовать пар; купивший аппарат ПВВК не попадает в школу. Трафик и доверие, которые генерирует личный бренд Ефимова (сотни видео, десятки тысяч подписчиков), не конвертируются в продажи соседних проектов. Объединение — это не новый сайт, а **единый клиент (ID), единая база и единый сценарий перехода** между продуктами.

## Методология и ограничения

- Проверены: публичные страницы сайтов в поисковом индексе, структура URL, заголовки и мета-описания, тарифы и цены, опубликованные на сайтах и маркетплейсах; отзывы (Otzovik, 2ГИС, маркетплейсы); PR-публикации; соцсети и видеоплатформы по публичным данным.
- **Ограничение:** прямой технический краулинг сайтов (скорость, код ответа, robots.txt, sitemap, Core Web Vitals) из среды подготовки был недоступен. Эти пункты вынесены в чек-лист «Проверить с доступом» в каждом файле — их нужно закрыть в первую неделю работ (PageSpeed Insights, Яндекс.Вебмастер, Метрика).
- Цифры подписчиков/охватов в соцсетях не зафиксированы — нужен доступ к статистике аккаунтов (или выгрузка от клиента). В каждом файле есть таблица для заполнения.
- Аудит маркетинговый, а не медицинский. Оценки медицинских утверждений даны только с точки зрения рекламного законодательства и репутационных рисков.

## Шкала оценок

Каждый блок оценён по 5-балльной шкале: **1** — отсутствует/критично, **2** — слабо, **3** — рабочее, но с потерями, **4** — хорошо, **5** — эталон.
