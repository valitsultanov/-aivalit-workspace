# /checkpoint — точка отката

Создай контрольную точку текущего состояния воркспейса: $ARGUMENTS

## Порядок действий

1. Проверь `git status`. Если есть несохранённые изменения — покажи их Валиту одной строкой и закоммить с осмысленным сообщением (conventional commits, как принято в репо).
2. Запиши точку в `.claude/checkpoints.log`:

```bash
echo "$(date +%Y-%m-%d-%H:%M) | <имя-точки> | $(git rev-parse --short HEAD)" >> .claude/checkpoints.log
```

3. Сообщи: имя точки, хеш коммита, что в неё вошло.

## Откат к точке

Если Валит просит вернуться к точке (`/checkpoint list`, «откатись к …»):

1. Покажи последние записи из `.claude/checkpoints.log`.
2. НИКОГДА не делай `git reset --hard` без явного подтверждения Валита.
3. Предпочитай мягкие варианты: `git revert`, новая ветка от нужного хеша, `git stash`.

## Имя точки

Если имя не передано — придумай короткое по сути изменений (например `prompt-v2-draft`, `bot-flow-ready`).
