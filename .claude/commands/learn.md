# /learn — копилка паттернов

Проанализируй текущую сессию и извлеки паттерны, которые стоит сохранить для будущих сессий.

## Что искать

1. **Промт-паттерны** — структуры и приёмы промтов, которые дали хороший результат (роль, формат, ограничения, примеры).
2. **Контент-находки** — форматы постов, сценариев, воронок, которые сработали или понравились Валиту.
3. **Решения проблем** — что сломалось, в чём была причина, что помогло (git, боты, инструменты, API).
4. **Правки Валита** — если Валит поправил результат, зафиксируй чем именно его версия лучше: тон, стиль, структура.
5. **Процессы воркспейса** — соглашения этого репозитория, обнаруженные по ходу работы.

## Что НЕ сохранять

- Разовые опечатки и мелкие правки.
- Специфику одного конкретного заказа/поста без переиспользуемой сути.
- Всё, что уже записано в существующих скиллах или правилах.

## Формат сохранения

Каждый паттерн — отдельный файл в `.claude/skills/learned/<короткое-имя>.md`:

```markdown
---
name: <короткое-имя>
description: <когда применять, одним предложением>
---

# <Название паттерна>

## Когда применять
...

## Паттерн
...

## Пример из сессии
...
```

## Порядок действий

1. Просмотри сессию, выпиши кандидатов (обычно 0–3, не выдумывай ради количества).
2. Покажи Валиту список кандидатов одной строкой на каждый.
3. Сохрани подтверждённые в `.claude/skills/learned/`.
4. Добавь строку об этом в сегодняшний файл `memory/`.
