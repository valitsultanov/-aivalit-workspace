# Barbie Salon — библия персонажей

## Мастер салона — Barbie ⭐ (постоянный персонаж)

Мастер-промпт (генерировать 10+ ретраев, выбрать эталон — он станет
референсом навсегда):

```text
Hyperrealistic photograph of a fashion doll beauty master, glossy smooth
plastic skin with subtle molded seams at the shoulders and elbows, visible
ball joints, rooted platinum blonde hair pulled into a sleek high ponytail,
painted facial features with glamorous makeup look, wearing a fitted blush
pink professional salon uniform dress with a small embroidered logo, tiny
gold hoop earrings, doll-proportioned figure, standing in a real modern
beauty salon interior, real professional salon equipment around her,
photorealistic environment, the doll is the only artificial-looking element,
soft studio lighting, shallow depth of field, vertical 9:16 composition,
ultra-detailed macro photography quality
```

### CHARACTER LOCK Барби (в каждый промпт)

```text
REFERENCE CHARACTER LOCK:
Use the exact same doll master character from the reference image. Keep the
exact original painted face, makeup, rooted platinum blonde ponytail, glossy
plastic skin with molded seams, ball joints, proportions, pink salon uniform
and earrings. She must always look like a doll — never like a human.
Character identity must remain 100% unchanged.
```

### Ключевое правило мира

```text
The doll characters have glossy plastic skin, molded seams and doll
proportions. The environment, furniture, tools and products are fully
photorealistic real-world objects. Only the dolls are dolls.
```
Этот блок — в каждый промпт сцены. Он держит формулу «куклы кукольные,
мир настоящий».

## Куклы-клиенты (ротация)

У каждой клиентки — **встроенная «поломка»**, считываемая за секунду,
которая чинится реальной бьюти-услугой. Типажи:

| Кукла | «Поломка» | Услуга |
|---|---|---|
| **Винтажная Барби 90-х** | Пожелтевший пластик, потёртости | Пилинг/осветление, «омоложение» |
| **Кукла со стёртым лицом** | Краска лица стёрлась от времени | Перманентный макияж (репейнт как процедура) |
| **Кукла-колтун** | Волосы дыбом, спутаны, посечены | Кератин, ботокс волос, полировка |
| **Кукла с «шрамом»** | Царапина/скол на щеке или руке | Шлифовка рубцов, филлер, ретушь |
| **Кукла с трещинами-«морщинами»** | Кракелюр на лице | Ботокс/биоревитализация |
| **Выгоревшая блондинка** | Зелёный оттенок волос (хлорка!) | Сложное окрашивание, тонирование |
| **Кукла из 2000-х с тату-стикерами** | Облезшие наклейки | Перекрытие: настоящая тату-машинка, новая тату |
| **«Оторва»-кукла** | Полулысая (детская стрижка ножницами) | Rerooting = «наращивание» |
| **Бабушка-кукла** | Всё сразу: винтаж 60-х | Полный makeover-марафон (спецэпизод) |

Каждой клиентке при вводе: мастер-кадр «до» на нейтральном фоне + вырезка
без фона + свой mini-LOCK (3–4 неизменные детали).

## Инструменты (всегда фотореализм, макро)

Настоящие: кисти и аэрограф, тату-машинка, утюжок и фольга, миски с
красителем, шприцы-дозаторы, пинцеты, УФ-лампа, пароочиститель, машинка для
полировки, иглы для rerooting. Руки Барби держат реальный инструмент —
фирменный кадр серии.
