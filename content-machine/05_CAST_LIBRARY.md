# 05 — Кастинг-библиотека пациентов (бьюти-трансформации)

Главный герой всех эпизодов — **Доктор AiValit** (см. `01_CHARACTER_BIBLE.md`).
Пациенты — ротация. Критерий отбора: персонаж должен иметь **встроенную
бьюти-«проблему»**, которая узнаваема за 1 секунду и даёт мощное «до → после».

Виральность: 🔥🔥🔥 — снимать в первую очередь, 🔥🔥 — сильный второй эшелон,
🔥 — ситуативно (под конкретный смысл/интеграцию).

## Правила ввода нового пациента в серию

1. **Мастер-кадр по образцу Peach** (`01_CHARACTER_BIBLE.md`): Pixar-style 3D
   антропоморф, полный рост, сплошной фон, студийный свет, 9:16 + свой
   постоянный набор аксессуаров (у каждого пациента — 2–3 фирменные детали,
   как шуба и сумка у персика).
2. **Свой CHARACTER LOCK** с перечислением неизменных деталей.
3. Вырезка без фона → референс.
4. Доктор AiValit — в каждом эпизоде по своему фото-референсу.
5. Трансформация всегда с ограничителем (20–30%, no deformation) и
   комедийная, не жуткая: тон — «милота + абсурд», не боди-хоррор.

## Границы провокации (чтобы не улететь в бан)

1. Подтекст — только через метафору. В промптах и в кадре — исключительно
   «фрукт + косметическая процедура», никаких прямых формулировок.
2. Никакой обнажёнки-антропоморфики сверх того, что уже есть у персика
   (фрукт без одежды = фрукт, это норма жанра).
3. Доктор всегда профессионален и этичен — комедия строится на реакциях
   и абсурде, а не на кринже. Отказ доктора («вам не нужно») — фирменный ход.
4. Боль/процедуры — мультяшно, без крови и страданий (кактус не морщится).
5. Каждый провокационный эпизод заканчивается позитивным твистом
   (принятие себя / сатира на индустрию) — это защита от репортов и
   причина шерить.
