# 05 — Кастинг-библиотека пациентов (бьюти-трансформации)

Главный герой всех эпизодов — **Доктор AiValit** (см. `01_CHARACTER_BIBLE.md`).
Пациенты — ротация. Критерий отбора: персонаж должен иметь **встроенную
бьюти-«проблему»**, которая узнаваема за 1 секунду и даёт мощное «до → после».

Виральность: 🔥🔥🔥 — снимать в первую очередь, 🔥🔥 — сильный второй эшелон,
🔥 — ситуативно (под конкретный смысл/интеграцию).

## S-tier — максимальный вирал 🔥🔥🔥

| Персонаж | Встроенная «проблема» | Процедура | До → После | Панчлайн |
|---|---|---|---|---|
| 🍑 **Персик** (действующая звезда) | Формы + пушок | Филлеры, ботокс, лазер | см. ep01–ep02 | Уже работает |
| 🍇 **Изюм → Виноград** | Сморщенность | Биоревитализация, «увлажнение» | Сухой сморщенный изюм → упругая глянцевая виноградина | Обратная эволюция — идеальный «до/после» в одном кадре |
| 🥝 **Киви** | Волосатость | Лазерная эпиляция | Пушистый бурый шарик → гладкий изумрудный | Половина гладкая, половина пушистая — паника на середине процедуры |
| 🐼 **Панда** | Тёмные круги под глазами | Патчи, осветление, консилер | Чёрные «синяки» → свежий взгляд | Панда без кругов = другое животное, кризис идентичности |
| 🐶 **Мопс** | Морщины и складки | Ботокс, лифтинг | Складчатая морда → «натянутый» глянец | Мопс перестал узнавать себя в зеркале, просит вернуть складки |
| 🍓 **Клубника** | «Поры» (семечки) | Чистка пор, пилинг | Семечки-«чёрные точки» → гладкая глянцевая | ASMR-выдавливание семечек — жанр очистки пор сам по себе виральный |
| 🐍 **Змея** | Старая кожа | «Пилинг» = линька | Тусклая матовая → блестящая новая кожа, старая сползает чулком | Пилинг здорового человека: сняли ВСЮ кожу целиком |

## Правила ввода нового пациента в серию

1. **Мастер-кадр по образцу Peach** (`01_CHARACTER_BIBLE.md`): Pixar-style 3D
   антропоморф, полный рост, сплошной фон, студийный свет, 9:16 + свой
   постоянный набор аксессуаров (у каждого пациента — 2–3 фирменные детали,
   как шуба и сумка у персика).
2. **Свой CHARACTER LOCK** с перечислением неизменных деталей.
3. Вырезка без фона → референс.
4. Доктор AiValit — в каждом эпизоде по своему фото-референсу.
5. Трансформация всегда с ограничителем (20–30%, no deformation) и
   комедийная, не жуткая: тон — «милота + абсурд», не боди-хоррор.
