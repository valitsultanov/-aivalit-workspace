# 🍑 AiValit Content Machine — виральные видео со связкой «Peach»

Контент-машина для серийного производства виральных вертикальных видео (9:16)
с постоянным 3D-персонажем. Исходная связка Валита («персик в бьюти-клинике»)
разобрана на формулу и масштабирована в библиотеку сценариев.

## Структура

| Файл / папка | Что внутри |
|---|---|
| `00_PIPELINE.md` | Полный производственный пайплайн: инструменты, порядок шагов, правила |
| `01_CHARACTER_BIBLE.md` | Библия персонажа: мастер-промпты, CHARACTER LOCK, правила референсов |
| `02_PROMPT_TEMPLATES.md` | Переиспользуемые шаблоны промптов (image, edit, first/last frame, i2v) |
| `03_EPISODE_FORMULA.md` | Универсальная формула эпизода (5 актов) + чеклист качества |
| `04_SCENARIO_LIBRARY.md` | Библиотека сценариев для масштабирования (12+ идей по формуле) |
| `05_CAST_LIBRARY.md` | Кастинг пациентов (фрукты/овощи/звери) с оценкой виральности; доктор AiValit — постоянный герой |
| `episodes/ep01_lip_filler_clinic/` | Эпизод-01 — исходная связка, дословно, шот за шотом |
| `projects/barbie_salon/` | Проект «Barbie Salon»: кукольный бьюти-салон, 3 линии контента, B2B-оффер салонам |
| `generator/` | Шаблон нового эпизода + скрипт генерации папки эпизода |

## Быстрый старт нового эпизода

```bash
python3 content-machine/generator/new_episode.py "ep02_dentist_veneers" "Стоматология: виниры"
```

Скрипт создаст `episodes/ep02_dentist_veneers/EPISODE.md` из шаблона —
дальше заполняешь промпты по `03_EPISODE_FORMULA.md` и `02_PROMPT_TEMPLATES.md`.

## Главные правила (из практики связки)

1. **Ретраи — норма.** Правильный кадр — это 3–10+ попыток с правкой промпта.
2. **ChatGPT + Gemini параллельно** на каждый кадр, берём лучший результат.
3. **CHARACTER LOCK в каждом промпте** — иначе персонаж «уплывает».
4. **Референсы персонажа — без фона**, чтобы не путать модель.
5. **First/last frame в Kling** — для контролируемого движения.
6. **Меняй позу второстепенного персонажа** между кадрами — иначе он «заморожен» в видео.
7. **Ограничители трансформации** («20-30% only, no deformation») — обязательны.
