# 00 — Производственный пайплайн

Полный цикл: идея → кадры → видео-фрагменты → монтаж → публикация.

## Инструменты

| Этап | Инструмент | Зачем |
|---|---|---|
| Генерация изображений | **ChatGPT (GPT-image) + Gemini одновременно** | Один и тот же промпт в оба, выбираем лучший выход — модели дают разные результаты |
| Удаление фона | любой remover (или Higgsfield `remove_background`) | Референсы персонажа подаём БЕЗ фона |
| Image-to-video (основной) | **Google Omni Flash** | Базовые оживления кадров |
| Image-to-video (точный контроль) | **Kling AI** | First/last frame, статичная камера, деликатные движения |
| Финальный монтаж | **CapCut** (или любой редактор) | Склейка фрагментов, музыка, SFX |

## Порядок производства эпизода

### Шаг 0 — Сценарий
Выбери сценарий из `04_SCENARIO_LIBRARY.md` (или добавь новый) и создай
эпизод через `generator/new_episode.py`. Распиши 5 актов по `03_EPISODE_FORMULA.md`.

### Шаг 1 — Персонаж и локация
1. Мастер-кадр персонажа — уже есть (`01_CHARACTER_BIBLE.md`). Для нового
   образа (без шубы, профиль, изменённые губы и т.п.) — правь мастер-кадр
   промптом «Keep the same picture, only …».
2. Сгенерируй кадр локации со специалистом (реальный человек-референс + брендинг).

### Шаг 2 — Ключевые кадры (изображения)
Для каждого шота:
1. Собери референсы: персонаж (без фона!) + локация/специалист.
2. Промпт = `REFERENCE CHARACTER LOCK` + описание шота (см. `02_PROMPT_TEMPLATES.md`).
3. Генерируй в ChatGPT и Gemini параллельно, ретрай до попадания (норма — 3–10+ попыток).
4. Если в видео будут участвовать оба кадра (first/last frame) — проверь, что
   второстепенные персонажи РАЗЛИЧАЮТСЯ по позе между кадрами.

### Шаг 3 — Видео-фрагменты
- Обычные шоты → **Omni Flash**: кадр + i2v-промпт.
- Точные шоты → **Kling**:
  - одиночный кадр + i2v-промпт со `Static camera` и перечислением микро-движений;
  - или пара first/last frame (например «без круга» → «с кругом») + промпт,
    описывающий ТОЛЬКО переход: «…slowly draws a white circle. Camera stays
    still. No other movement.»

### Шаг 4 — Монтаж (CapCut)
1. Склей фрагменты в порядке актов.
2. Музыка (трендовый звук площадки) + SFX на ключевые моменты
   (штрих маркера, «пшик», звук шприца, дверь, каблуки).
3. Хук в первые 1–2 секунды. Длительность цели: 15–35 сек.
4. Экспорт 9:16, 1080×1920.

## Правила, которые нельзя нарушать

- **CHARACTER LOCK** — в каждом image-промпте с персонажем.
- **Референсы персонажа без фона.**
- **Один шот = одно действие.** Не проси модель сделать два движения сразу.
- **Ограничители в i2v:** `no camera movement`, `subtle natural movements`,
  для трансформаций — явный предел («20-30% only, no exaggerated…, no deformation»).
- **Минимальные правки — через «Keep the picture, only …»**, а не через новый промпт.
- **Смена позы второстепенных персонажей** между смежными кадрами, чтобы
  в i2v они не стояли статуями.

## Масштабирование (контент-машина)

- 1 эпизод = 6–9 шотов ≈ 1 видео 20–30 сек.
- Персонаж и локации переиспользуются → себестоимость каждого следующего
  эпизода падает: меняются только сценарий и 2–4 новых кадра.
- Серийность: одна локация (клиника) тянет 3–5 эпизодов (разные процедуры),
  затем смена локации из `04_SCENARIO_LIBRARY.md`.
- Кросс-постинг: TikTok / Reels / Shorts / VK Клипы — один мастер-файл,
  разные обложки и подписи.
