# Проект «Катализатор»

Статус: черновик ТЗ (2026-11-23), требует уточнений от Валита.

## Суть
Валит присылает материалы (фото, видео, референсы, тексты) → Катализатор
перерабатывает их через Higgsfield MCP:
- меняет стилистику (style transfer, новый визуальный язык);
- меняет / заменяет персонажей визуально, сохраняя консистентность;
- собирает результат под задачу (контент, реклама, драма-серия).

## Инструмент
- Higgsfield MCP — подключён, тариф Ultra.
- Персонажи и локации хранятся как Elements (`<<<element_id>>>` в промпте).
- Уже есть Elements: Kael, Aria, Cora, Lyra, Mia, Naomi + реквизит
  (в т.ч. золотой скорпион — похоже на зодиакальную линию).

## База «СКИНЫ» (астрология)
- Не найдена ни в репозитории, ни в проектах Higgsfield.
- Нужно: где лежит, формат (12 знаков? образы/палитры/промпты?).
- План: оформить каждый скин как карточку (`skins/<знак>.md`):
  образ, палитра, свет, фактуры, промпт-шаблон, Element-референс.

## Пайплайн (v0)
1. Приём материала → загрузка в Higgsfield (media_upload).
2. Выбор скина / целевого стиля.
3. Генерация (по умолчанию — GPT Image 2.6 / Nano Banana Pro; видео —
   Seedance 2.0 / Kling 3.0) с оценкой стоимости до запуска.
4. Показ результата → правки → сохранение в проект Higgsfield «Катализатор».
